## 🔸 What's Inside?

```
.
├── nixos             # System config (flake-based, goes in /etc/nixos)
├── home-manager      # Standalone flake for user-level config
├── nvim              # My Neovim setup (LazyVim-based, lives in ~/.config/nvim)
├── hyprland          # Hyprland window manager config (in ~/.config/hypr)
├── waybar            # Waybar config (in ~/.config/waybar)
├── kitty             # Kitty terminal config
├── rofi              # Rofi app launcher config
├── swaync            # SwayNC notification daemon config
├── ghostty           # Ghostty terminal config (available)
└── starship.toml     # Starship prompt config
```

## 🔸 Why NixOS?

I use **NixOS** 'cause I like things that don't break randomly. It's fully declarative, super neat, and once you get it—kinda addictive. ( nah don't listen to ai, I just wanted that cool flake logo, and nixos was my first ever linux distro too idk man nix looks cool to me and it is cool )

## 🔸 Home Manager (standalone flake)

Using **Home Manager** as a standalone flake—separate from the NixOS flake but integrated via shared inputs. Handles all my user config declaratively.

> Wanna try it? Here's a [good video to start with](https://youtu.be/FcC2dzecovw?si=HUbmg8MK8kuPHIOi).

## 🔸 Neovim (LazyVim)

Yeah I use Neovim with **LazyVim**. This setup's fast, simple, and gets out of the way so I can actually write code.

Path: `~/.config/nvim`

## 🔸 Hyprland & Friends

Using **Hyprland** as my main window manager with:

- **swww** for wallpapers
- **hyprlock** for lock screen
- **Waybar** for the status bar
- **Rofi** for the app launcher
- **Dunst** for notifications
- **DMS** (from Noctalia shell) for spotlights, powermenu, control center, notepad

---

## 🔸 Terminals

Running **Kitty** as my primary terminal with themes. Also have Ghostty config available.
